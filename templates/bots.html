API ربات‌ها

همهٔ مسیرها زیر /bot/api/<token>/ هستند؛ احرازهویت با خودِ توکن است. محدودیت: ۳۰ درخواست در ثانیه برای هر ربات.

GET /bot/api/‹token›/getMe

مشخصات ربات (id، username).

POST /bot/api/‹token›/sendMessage

مقدار chat_id یا user_id + text. دایرکت با user_id به‌صورت خودکار ساخته می‌شود؛ در گروه، ربات باید عضو آن گروه باشد.

GET /bot/api/‹token›/getUpdates?offset=0

پیام‌هایی که کاربر در دایرکت ربات یا در گروهی که عضو آن است فرستاده؛ با offset از آخرین update_id ادامه بده.

POST /bot/api/‹token›/setWebhook

مقدار url؛ به‌جای پُلب، هر آپدیت به‌صورت POST JSON به آن آدرس فرستاده می‌شود. برای برچیدن، deleteWebhook.

کتابخانهٔ کمکی (nakheyr_bot)

from nakheyr_bot import NakheyrBot

bot = NakheyrBot(token="YOUR_TOKE...HERE")

def on_update(update):
    msg = update.get('message', {})
    if msg.get('content') == 'سلام':
        bot.send_message(user_id=msg['sender_id'], text='درود بر شما')

bot.run_forever(on_update)
