API ربات‌ها

همهٔ مسیرها زیر /bot/api/<token>/ هستند؛ احرازهویت با خودِ توکن است. محدودیت: ۳۰ درخواست در ثانیه برای هر ربات.

GET /bot/api/‹token›/getMe

مشخصات ربات (id، username).

POST /bot/api/‹token›/sendMessage

مقدار chat_id یا user_id + text. دایرکت با user_id به‌صورت خودکار ساخته می‌شود؛ در گروه، ربات باید عضو آن گروه باشد.

GET /bot/api/‹token›/getUpdates?offset=0

پیام‌ها و کلیک‌های دکمه‌ها؛ با offset از آخرین update_id ادامه بده.

POST /bot/api/‹token›/setWebhook

مقدار url؛ به‌جای پُلب، هر آپدیت به‌صورت POST JSON به آن آدرس فرستاده می‌شود. برای برچیدن، deleteWebhook.

POST /bot/api/‹token›/answerCallbackQuery

پاسخ به کلیک دکمه‌ی شیشه‌ای؛ text اختیاری است.

دکمه‌های شیشه‌ای (Inline Buttons)

به sendMessage یک buttons اضافه کن: آرایه‌ای از ردیف‌ها، هر دکمه با text و data (برای کال‌بک) یا url (برای باز کردن لینک). حداکثر ۸ ردیف و ۴ دکمه در هر ردیف.

{
  "user_id": 42,
  "text": "یکی رو انتخاب کن:",
  "buttons": [
    [{"text": "👍 آره", "data": "yes"}, {"text": "👎 نه", "data": "no"}],
    [{"text": "سایت ما", "url": "https://example.com"}]
  ]
}

وقتی کاربر روی دکمه‌ی data بزند، در getUpdates یک آپدیت با کلید callback_query می‌گیری که data و from و message دارد.

آموزش: ربات با TeleBot (pyTelegramBotAPI)

نخیر همان شکل API تلگرام را دارد؛ پس همان کتابخانهٔ محبوب pyTelegramBotAPI با یک api_baseurl سفارشی کار می‌کند.

pip install pyTelegramBotAPI requests

import telebot

TOKEN = "TOKEN_ربات_تو"
BASE  = "http://127.0.0.1:5000/bot/api/"

bot = telebot.TeleBot(TOKEN, api_baseurl=BASE, threaded=False)

@bot.message_handler(commands=["start"])
def start(message):
    bot.send_message(message.chat.id, "سلام! من ربات نخیرم 👋")

@bot.message_handler(func=lambda m: True)
def echo(message):
    bot.send_message(message.chat.id, "گفتی: " + (message.text or ""))

bot.infinity_polling(timeout=10, long_polling_timeout=5)

اگر می‌خواهی بدون کتابخانه و فقط با requests کار کنی:

import requests, time

TOKEN = "TOKEN_ربات_تو"
API   = f"http://127.0.0.1:5000/bot/api/{TOKEN}"
offset = 0

while True:
    r = requests.get(f"{API}/getUpdates", params={"offset": offset}).json()
    for up in r.get("updates", []):
        offset = up["update_id"]
        msg = up.get("message")
        if msg:
            requests.post(f"{API}/sendMessage", json={
                "user_id": msg["sender_id"],
                "text": "دریافت شد: " + (msg.get("content") or ""),
                "buttons": [[{"text": "باشه", "data": "ok"}]],
            })
        cb = up.get("callback_query")
        if cb:
            requests.post(f"{API}/answerCallbackQuery", json={"text": "کلیک شد: " + cb["data"]})
    time.sleep(2)

نکته: در getUpdates هر پیام کلیدهای sender_id، content، chat_id و buttons را دارد. برای وب‌هوک، همان JSON را روی آدرس خودت دریافت می‌کنی.
