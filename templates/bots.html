API ربات‌ها

همهٔ مسیرها زیر /bot/api/<token>/ هستند؛ احرازهویت با خودِ توکن است. محدودیت: ۳۰ درخواست در ثانیه برای هر ربات. ربات‌ها در کانال پیام نمی‌فرستند؛ در گروه باید عضو باشند و برای عملیات مدیریتی نقش مدیر/مالک داشته باشند.

پیام و رسانه

GET /bot/api/‹token›/getMe

مشخصات ربات (id، username، name، bio، دستورات).

POST /bot/api/‹token›/sendMessage

مقدار chat_id یا user_id + text. دایرکت با user_id به‌صورت خودکار ساخته می‌شود؛ در گروه، ربات باید عضو آن گروه باشد. گزینه‌های reply_to و buttons را هم قبول می‌کند.

POST /bot/api/‹token›/sendPhoto | sendVideo | sendAudio | sendVoice | sendDocument | sendAnimation

میدیا با url (سروور دانلودش می‌کند، تا ۵۰ مگ) یا file_id (مسیر uploads/… یک پیام قبلی، مثلاً از یک آپدیت دریافتی). عنوان تصویر/میدیا با caption. گیف: sendAnimation فقط gif یا mp4 بدون صدا.

POST /bot/api/‹token›/sendPoll

question + options (۲ تا ۶) + multi. فقط در گروه/کانال (در کانال فقط با نقش مدیر).

POST /bot/api/‹token›/editMessageText | deleteMessage

ویرایش/حذف پیام؛ با chat_id + message_id. ویرایش فقط پیامِ خودِ ربات؛ حذف برای رباتِ مدیر، پیام دیگران را هم می‌پذیرد. در ویرایش می‌توانی buttons جدید بگذاری.

POST /bot/api/‹token›/sendChatAction

action: typing / upload_photo / record_audio / … — نشانگر «دارد تایپ می‌کند» برای اعضای گپ.

مدیریت گپ (نیازمند نقش مدیر/مالک ربات در آن گپ)

POST /bot/api/‹token›/getChat | getChatMembers | getChatMember

اطلاعات گپ، لیست اعضا با نقش‌ها، و وضعیت/نقش یک کاربر در گپ. ربات باید عضو گپ باشد.

POST /bot/api/‹token›/kickChatMember | banChatMember | unbanChatMember | promoteChatMember

اخراج/بلاک/لغو-بلاک/تغییر نقش عضو با user_id. تغییر نقش فقط برای مالک؛ is_admin در promote. بلاک موقت (until_date) پشتیبانی نمی‌شود.

POST /bot/api/‹token›/leaveChat | setChatTitle | setChatDescription | pinChatMessage | unpinChatMessage

ترک گپ، تغییر نام/توضیح، پین/لغو پین پیام (بدون message_id = پاک کردن همهٔ پین‌ها). مالک نمی‌تواند گپ را ترک کند.

POST /bot/api/‹token›/exportChatInviteLink

لینک گپ (با username عمومی) که کاربر با آن وارد می‌شود.

هویت و دستورات

POST /bot/api/‹token›/setMyName | setMyDescription | setMyCommands

نام/توضیح و فهرست دستورات ربات (commands: آرایه از {command, description}). خواندن با GET getMyCommands.

آپدیت‌ها و وب‌هوک

GET /bot/api/‹token›/getUpdates?offset=0

هر رویداد با یک کلید: message، edited_message، callback_query (کلیک دکمه)، member_joined / member_left، poll_vote / poll، message_reaction. با offset از آخرین update_id ادامه بده؛ مصرف‌شده‌ها ۷ روز نگهداری می‌شوند.

POST /bot/api/‹token›/setWebhook | deleteWebhook

مقدار url؛ به‌جای پُل، هر آپدیت به‌صورت POST JSON به آن آدرس فرستاده می‌شود.

POST /bot/api/‹token›/answerCallbackQuery

پاسخ به کلیک دکمه‌ی شیشه‌ای؛ text اختیاری است.

دکمه‌های شیشه‌ای (Inline Buttons)

به sendMessage یا editMessageText یک buttons اضافه کن: آرایه‌ای از ردیف‌ها، هر دکمه با text و data (برای کال‌بک) یا url (برای باز کردن لینک). حداکثر ۸ ردیف و ۴ دکمه در هر ردیف.

{
  "user_id": 42,
  "text": "یکی رو انتخاب کن:",
  "buttons": [
    [{"text": "👍 آره", "data": "yes"}, {"text": "👎 نه", "data": "no"}],
    [{"text": "سایت ما", "url": "https://example.com"}]
  ]
}

وقتی کاربر روی دکمه‌ی data بزند، در getUpdates یک آپدیت با کلید callback_query می‌گیری که data و from و message دارد.

آموزش: ربات با TeleBot (pyTelegramBotAPI)

نخیر همان شکل API تلگرام را دارد؛ پس همان کتابخانهٔ محبوب pyTelegramBotAPI با یک api_baseurl سفارشی کار می‌کند.

pip install pyTelegramBotAPI requests

import telebot

TOKEN = "TOKEN_ربات_تو"
BASE  = "http://127.0.0.1:5000/bot/api/"

bot = telebot.TeleBot(TOKEN, api_baseurl=BASE, threaded=False)

@bot.message_handler(commands=["start"])
def start(message):
    bot.send_message(message.chat.id, "سلام! من ربات نخیرم 👋")

@bot.message_handler(func=lambda m: True)
def echo(message):
    bot.send_chat_action(message.chat.id, "typing")
    bot.send_message(message.chat.id, "گفتی: " + (message.text or ""),
                     reply_markup=[["باشه", "نه"]])

bot.infinity_polling(timeout=10, long_polling_timeout=5)

اگر می‌خواهی بدون کتابخانه و فقط با requests کار کنی:

import requests, time

TOKEN = "TOKEN_ربات_تو"
API   = f"http://127.0.0.1:5000/bot/api/{TOKEN}"
offset = 0

while True:
    r = requests.get(f"{API}/getUpdates", params={"offset": offset}).json()
    for up in r.get("updates", []):
        offset = up["update_id"]
        msg = up.get("message")
        if msg:
            if msg.get("content") == "/start":
                requests.post(f"{API}/sendChatAction", json={"user_id": msg["sender_id"], "action": "typing"})
                requests.post(f"{API}/sendMessage", json={
                    "user_id": msg["sender_id"],
                    "text": "سلام! چطور می‌تونم کمکت کنم؟",
                    "buttons": [[{"text": "راهنما", "data": "help"}]],
                })
            else:
                requests.post(f"{API}/sendMessage", json={
                    "user_id": msg["sender_id"],
                    "text": "دریافت شد: " + (msg.get("content") or ""),
                })
        cb = up.get("callback_query")
        if cb:
            requests.post(f"{API}/answerCallbackQuery", json={"text": "کلیک شد: " + cb["data"]})
            requests.post(f"{API}/editMessageText", json={
                "chat_id": cb["message"]["chat_id"],
                "message_id": cb["message"]["id"],
                "text": "انتخاب شد: " + cb["data"],
            })
        mj = up.get("member_joined")
        if mj:
            requests.post(f"{API}/sendMessage", json={
                "chat_id": mj["chat"]["id"],
                "text": f"خوش اومدی {mj['user']['display_name']} 🎉",
            })
    time.sleep(2)

نکته: در getUpdates هر پیام کلیدهای sender_id، content، chat_id، msg_type و buttons را دارد. برای وب‌هوک، همان JSON را روی آدرس خودت دریافت می‌کنی.
